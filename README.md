# SIGNAL — Sistema móvil de comunicación descentralizada

## Descripción
SIGNAL es una aplicación nativa para Android cuyo objetivo es facilitar la comunicación entre dispositivos cercanos sin depender de Internet.

## Tecnologías
- **Lenguaje:** Kotlin
- **Plataforma:** Android
- **Interfaz:** Jetpack Compose
- **IDE:** Android Studio
- **Sistema de construcción:** Gradle con Kotlin DSL
- **Control de versiones:** Git y GitHub

## Estructura del proyecto
- `communication/`: descubrimiento de dispositivos y mensajería.
- `data/`: acceso a datos y repositorios.
- `domain/`: modelos y lógica de la aplicación.
- `ui/`: pantallas y componentes de la interfaz.
